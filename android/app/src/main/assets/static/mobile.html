Smooth Ramp consent
Read the full notice before enabling this optional feature.

Without Smooth Ramp, the controller sends one live luminance update per hour to keep the lamp in step with the schedule. Smooth Ramp increases this to about every 2 minutes, but only when calculated channel values change.

Neither mode intentionally rewrites the lamp's stored 24-hour schedule. The full schedule is kept on the ESP32 controller, and the lamp receives only the current output level.

However, the Noo-Psyche lamp firmware is closed. We cannot verify whether the lamp stores live luminance commands internally or how it manages write wear. Smooth Ramp sends commands more frequently than the hourly default, which may increase any internal write activity.

Use Smooth Ramp at your own discretion.
